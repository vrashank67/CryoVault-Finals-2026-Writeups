# cairn

## Summary

`chall` is a stripped x86-64 ELF with no visible interpreter loop: `main` reads a
line, requires exactly 32 bytes, and then runs a bytecode program through a
compact inlined VM whose "handlers" are heavily SSE2-vectorized. The bytecode
lives in `.rodata` at `0x401300` (2 bytes per instruction: opcode + immediate)
and is dispatched through a 6-entry function-pointer table at `0x4012a0`. The
final state is `memcmp`'d against 32 bytes at `0x4012e0`.

Crucially, every opcode is a **bytewise bijection** — XOR, add, rotate, an
affine S-box, and a permutation — so the checker is fully invertible by hand.
Running the 25 instructions backwards from the target yields the flag, and the
recovered string is confirmed by the binary printing
`correct: the flag is your input`.

## Solution

1. **Recover the VM semantics from the dispatch table.** The jump table entries
   are `0x4012a0 -> {0x400713, 0x40078f, 0x40074e, 0x40063b, 0x400614,
   0x4005bf}`, i.e. opcodes `1..5` are XOR, ADD, ROTL, SBOX, PERM (index 0 is
   the "nop"/next-insn path). Decoding `0x401300` as `[opcode][imm]` pairs gives
   five identical rounds followed by opcode `6` (halt):

   ```
   xor byte_i ^= (i + imm)          # imm = 0x5a, 0xa7, 0x1c, 0xe3, 0x90
   add byte_i += (3*i + imm)        # imm = 0x31, 0x6d, 0xb8, 0x4f, 0x22
   rot byte_i  = rotl8(byte_i, imm) # imm = 3, 5, 1, 7, 2
   sbox byte_i = 7*byte_i + 13 mod 256
   perm out[perm[i]] = in[i]        # perm table @0x401340
   ```

   The S-box is *not* AES-like: the SSE2 prelude at `0x400430` computes
   `8x - x + 0x0d` over bytes (three `paddb` doublings, one `psubb`, then
   `+0x0d`), with the byte index sequence generated by the `punpck`/`packuswb`
   chain being plain `0..255` (verified in gdb at `0x403060`). Hence
   `sbox(x) = (7x + 13) & 0xff`, invertible since `7^-1 = 183 (mod 256)`.
   The `add` tables at `0x4013a0/0x4013b0` are `0,3,6,...` so the constant is
   exactly `3*i + imm`; the XOR tables at `0x401380/0x401390` are `0..31`, so
   it is exactly `i + imm`.

2. **Invert the five rounds in reverse order** from the 32-byte target:
   un-permute (`in[i] = out[perm[i]]`), inverse S-box, rotate right, subtract
   `3i + imm`, XOR `i + imm`. Because each step is bijective, the result is
   unique. The recovered plaintext is

   `isfcr{c41rn_vm_r3v3rs3_by_h4nd1}`

   which satisfies the required `isfcr{...}` shape and length 32.

3. **Verify against the real checker.** The script re-runs its forward model on
   a known input and matches a gdb dump of the checker's own state
   (`'A'*32 -> 052cdcde...3e87fb`), then feeds the candidate to the binary:
   it prints `correct: the flag is your input`, while a one-byte mutation
   prints `nope`.

```python
#!/usr/bin/env python3
"""cairn solver: parse the ELF, emulate the bytecode VM, invert the check."""
import struct, sys

HANDLERS = {0x40078F: "xor", 0x40074E: "add", 0x40063B: "rot",
            0x400614: "sbox", 0x4005BF: "perm"}

class ELF:  # ELF64 LE, vaddr -> file bytes
    def __init__(self, path):
        self.d = open(path, "rb").read()
        e_shoff, = struct.unpack_from("<Q", self.d, 0x28)
        e_shentsize, e_shnum = struct.unpack_from("<HH", self.d, 0x3A)
        self.secs = []
        for i in range(e_shnum):
            o = e_shoff + i * e_shentsize
            _n, _t, _f, addr, off, size = struct.unpack_from("<IIQQQQ", self.d, o)
            self.secs.append((addr, off, size))
    def at(self, va, n):
        for a, off, size in self.secs:
            if size and a <= va and va + n <= a + size:
                return self.d[off + (va - a): off + (va - a) + n]
        raise ValueError(hex(va))
    def u64(self, va):
        return struct.unpack("<Q", self.at(va, 8))[0]

sbox     = lambda x: (7 * x + 13) & 0xFF
sbox_inv = lambda v: ((v - 13) * 183) & 0xFF
rotl8 = lambda x, k: (((x << (k & 7)) | (x >> (8 - (k & 7)))) & 0xFF) if k & 7 else x
rotr8 = lambda x, k: (((x >> (k & 7)) | (x << (8 - (k & 7)))) & 0xFF) if k & 7 else x

def solve(path):
    e = ELF(path)
    target = e.at(0x4012E0, 32)
    perm   = list(e.at(0x401340, 32))
    disp   = [e.u64(0x4012A0 + 8 * i) for i in range(6)]
    opmap  = {op: HANDLERS[a] for op, a in enumerate(disp) if a in HANDLERS}
    prog   = e.at(0x401300, 0x40)
    insns, i = [], 0
    while prog[i] != 6:
        insns.append((opmap[prog[i]], prog[i + 1])); i += 2

    def forward(state):
        s = list(state)
        for name, imm in insns:
            if name == "xor":  s = [v ^ ((j + imm) & 0xFF) for j, v in enumerate(s)]
            elif name == "add": s = [(v + 3 * j + imm) & 0xFF for j, v in enumerate(s)]
            elif name == "rot": s = [rotl8(v, imm) for v in s]
            elif name == "sbox": s = [sbox(v) for v in s]
            elif name == "perm":
                t = [0] * 32
                for j in range(32): t[perm[j]] = s[j]
                s = t
        return bytes(s)

    s = list(target)
    for name, imm in reversed(insns):
        if name == "xor":   s = [v ^ ((j + imm) & 0xFF) for j, v in enumerate(s)]
        elif name == "add": s = [(v - 3 * j - imm) & 0xFF for j, v in enumerate(s)]
        elif name == "rot": s = [rotr8(v, imm) for v in s]
        elif name == "sbox": s = [sbox_inv(v) for v in s]
        elif name == "perm": s = [s[perm[j]] for j in range(32)]
    flag = bytes(s)
    assert forward(flag) == bytes(target)          # inversion self-check
    return flag

if __name__ == "__main__":
    flag = solve(sys.argv[1] if len(sys.argv) > 1 else "chall").decode()
    print(flag)
    assert flag.startswith("isfcr{") and flag.endswith("}")
```
